# Reproducibility

This document provides plug-and-play reproduction with no undocumented manual
steps, addressing each requirement of the reproducibility review.

## 1. Environments (pinned)
| Stage | File | Purpose |
|---|---|---|
| 1 — DL | `envs/env_dl.yml` | ProteinBERT fine-tuning + OOF metafeature (TensorFlow 2.12, GPU) |
| 2 — ML | `envs/env_ml.yml` | Stacking + figures/tables (CPU; scikit-learn 1.2.2 etc.) |

```bash
conda env create -f envs/env_dl.yml      # -> pbertkla_dl
conda env create -f envs/env_ml.yml      # -> pbertkla_ml
```
> The legacy `requirements.txt` (TensorFlow 2.4) is retained only for reference;
> the deep-learning results were produced with TensorFlow 2.12 (`envs/env_dl.yml`).

## 2. Random seeds
Seed **42** throughout: `PBertKla_v3.py` and `generate_oof.py` (`--seed 42`,
`StratifiedKFold(random_state=42)`); ML stacking Optuna `seed=42`. The internal
validation split in the legacy `PBertKla.py`/`PBertKla_v2.py` uses
`random_state=0`. **Determinism:** results are fixed by (data + seed + pinned
versions + thread count); multithreaded LightGBM/XGBoost/CatBoost can vary AUROC
by ~±0.001 without changing any conclusion — set `PBK_THREADS=1` for bitwise
reproduction.
